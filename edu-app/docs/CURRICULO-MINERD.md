## Estrategia de actualización
1. Revisión periódica: tarea mensual (y antes de cada año escolar, julio-agosto) que consulta las páginas de ordenanzas de minerd/ministeriodeeducacion, educando.edu.do y el CNE; registra hash de cada PDF.
2. Import: script que convierte PDF/HTML a JSON candidato (extracción asistida + revisión humana), valida contra JSON Schema y lo guarda como nueva versión inmutable (`curriculum.version`) sin sobrescribir la anterior.
3. Diff: comparación estructural por `id` entre versiones (áreas, competencias, contenidos, indicadores añadidos/quitados/modificados) con informe legible; las migraciones de datos de estudiantes (calificaciones) se amarran a la versión con la que se evaluó.
4. Vigencia: campo `validity` + `status`; la app usa la versión con `from <= hoy` y status vigente; se mantiene el historial para años anteriores.
5. Calidad: cada dato con URL y confianza; los de confianza baja bloquean la publicación hasta verificación contra el texto oficial.
